# 素材総点検・制作記録

開始日: 2026-10-16
基準main: `67631f8c6a02ef7e7c55ec4b8a9247a0e8512f74`

ユーザー方針: 既存素材は破棄せず、全体を順番に作り直してゲームへ反映する。

## 共通仕様

旧 `assets/images/` は変更せず、新規素材を `assets/v2/` に保存する。盤面アイコンは透過PNG、正方形の余白、縮小時に分かる輪郭、統一した塗りと左上光源を持つ。拡大縮小は縦横比を保持する。セルは通常30〜40px、カスタムではさらに小さくなるため、原寸だけでなく縮小状態で確認する。

画像は内蔵image_genで個別に制作し、採用プロンプトを記録する。ゲーム内の単純な線・枠・数字・状態マークはコード描画を使う。音声は原曲・既存録音を用いない手続き生成の短い効果音とループ曲を作る。音のオン／オフと音量を用意する。

RPG_SIMPLEの確定ルールは変更しない。剣は不要・非消費、持ち越しなし、階得点リセット・総得点累計、エンドレス。未使用素材の完成は、新しいゲームルールの導入を意味しない。

## 制作順

1. 宝箱（閉／開）、金、地雷、旗、壁、敵（通常／撃破済み）、階段、鍵、剣。現行ゲームへ組み込む。
2. HUD、盤面・枠・ボタン、取得済み・階段ロックの表示、メニュー背景。旧版との比較画面を用意する。
3. 操作・公開・旗・宝箱・取得・撃破・解放・階移動・敗北・通常勝利の効果音と、メニュー／探索のBGMを制作・接続する。
4. 未使用分も新規制作する。コウモリ、ゴブリン、ボス、鉄鍵、銀鍵、薬3色、盾、つるはし、鶏、炎、木、水。専用ルール未実装のものは素材一覧へ収録する。
5. 縮小表示・アルファ・実ファイル形式・ロード経路・音声・回帰テストを確認し、進捗を更新する。

dummyは仮テクスチャの役割なので描画コードで生成する。敵・鍵・宝の別名やJPG／PNGの重複は新たに複製せず、参照を共有する。旧重複ファイル自体は保持する。

## 制作状況

ゲームで使う画像12点: 宝箱（閉／開）、金貨、地雷、旗、壁、金の鍵、剣、階段、スライム、撃破済みスライム、メニュー背景。

保管用画像14点: コウモリ、ゴブリン、ボス、鉄の鍵、銀の鍵、赤・青・黄の薬、盾、つるはし、鶏、炎、木、水。専用ルールを作る際に採用する。現行ゲームの初期ロード対象には含めない。

コード描画8点: dummy、未開放タイル、時計、総得点トロフィー、達成印、ロック、階数、取得時の光。`src/system/AssetPresentation.js` が生成する。状態を色だけに頼らず、宝箱の開閉・敵の姿・鍵穴／達成印で表す。

音声12点: ボタン、セル公開、旗、宝箱、取得、敵撃破、階段解放、次の階、地雷・敗北、通常勝利の10効果音（WAV）と、メニュー／探索の2ループ曲（OGG Vorbis）。22,050Hz・モノラル、合計393,413 bytes。全て `tools/build-audio.py` の決定的な合成で作成し、第三者の録音・楽曲は入力していない。

BootSceneが実在する画像12点と音12点をカタログから読み込む。AudioManagerはgame単位で維持し、階移動時に同一BGMを重複再生しない。メニューとゲーム画面に音のオン／オフ・音量操作を配置。初期音量35%、BGMはその28%で再生し、同種効果音の45ms以内の連打を抑制する。ブラウザの音声解除はPhaserの処理に従う。音量設定はページ再読込時に初期化される。

## 一覧と再制作

`index.html` の「新しい素材を見る」から [asset-review.html](../asset-review.html) を開く。新旧比較、30／40／120px表示、明暗・透過チェック背景、使用中／保管の絞り込み、全音声の試聴を備える。一覧ページ自体はPhaserやCDNに依存しない。

- [production.json](../assets/v2/production.json): 画像ごとの採用プロンプト、参照画像ID、生成原本の出力名、配布パス、寸法、透過、容量、SHA-256。
- [src/assets.js](../src/assets.js): 新旧対応、表示名、ゲームで使うキーとロード対象、音声パスをまとめた生成カタログ。
- [export-assets.cjs](../tools/export-assets.cjs): 生成原本のディレクトリを引数にして、縦横比と透過を保持した配布画像・カタログを再出力する。Node.jsとsharpが必要。原本のリサイズ以外の描き直しはしない。
- [build-audio.py](../tools/build-audio.py): Python・numpy・ffmpegで音声を再生成する。[analysis.json](../assets/v2/audio/analysis.json) はエンコード前の長さ・ピーク・RMS。

ゲーム実行に制作ツールのインストールは不要。画像原本は画像生成時の出力に保持し、リポジトリにはゲーム用書き出しを収録する。生成には揺らぎがあるため、同じプロンプトで再生成しても元の絵と同一にはならない。

- `npm test`: 43件成功。元の37件を維持し、素材の形式・ハッシュ、初回SE、欠損音の無視、重複BGM、消音・音量、縦横比、メニューボタンを確認。
- 全25アイコンのRGBA・256×256・透明／不透明画素の存在を確認。26画像の30／40／120px一覧と40pxのセル状態合成を目視。これは実ブラウザのスクリーンショットではなく、配布画像と実際の状態マーク描画コードから作った確認用画像。
- 音声12点をffmpegでデコードし、空音源・非有限値・クリッピングがないことを確認。デコード後のピークは0.381〜0.650。実スピーカーでの音質・ブラウザでの自動再生解除は未確認。
- 実ブラウザの描画・入力・CDN取得・音声再生は未検証。現在の環境ではChromiumをsandbox有効で起動できないため、実機確認を完了したとは扱わない。

実ブラウザ確認では、通常／RPGの開始、旗、宝箱の開閉と内容バッジ、敵の自動公開→手動撃破、階段のロック→解放、連続階層、メニュー往復時のBGM切替、音量0・消音からの復帰、素材一覧の旧画像と音声を確認する。
