## 開発方針

本プロジェクトは、単一の完成形へ早期収束させることを目的とせず、マインスイーパーを拡張したときに何が起こるかを検証する試作です。

単一セル方式と多層セル方式のどちらか一方を廃止せず、次のモードを並行して保持します。

1. CLASSIC
2. RPG_SIMPLE
3. RPG_LAYERED
4. EXPERIMENTAL

共通 UI と基盤を再利用しながら、盤面モデル、生成器、進行条件をモード単位で差し替えます。詳細は SPECIFICATION.md と HANDOFF.md を参照してください。
