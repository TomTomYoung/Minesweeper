## 1. 総合判定

通常モードは中核ロジックと画面構成が実装済みですが、実ブラウザでの回帰確認と自動テストがありません。

RPG モードは要素の表示と一部イベントが動く試作段階です。既存の RPG 仕様書が要求する多層セル、装備消費、敵との危険な相互作用、階段中心の勝利条件には達していません。

プロジェクト全体としては、機能追加より先に「起動を安定させる」「現行ロジックをテスト可能にする」「RPG のデータモデルを確定する」の三点が必要です。

## 3. 部分実装

### 3.1 RPG モード

宝、鍵、剣、敵、壁、階段の名前とイベントはありますが、設計書どおりには連携していません。

鍵は階段条件に使われます。剣は取得時に 50 点を加えるだけで、敵との戦闘に使われません。つるはしはデータにも UI にもありません。敵はクリックするだけで必ず撃破できます。

### 3.2 宝の二段階操作

ロジックは公開と取得の二段階ですが、BoardManager.updateBoardUI は公開状態と旗を中心に同期し、state 2 と treasureContent の表示更新を十分に反映しません。

### 3.3 スコア通知

GameSession は TREASURE_GOLD を処理して得点を加えますが、GameFlowController は TREASURE という別名を待っています。このため、得点は増えても宝発見メッセージと効果音が発火しません。

### 3.4 保存と音声

SaveManager と AudioManager はクラスだけ存在し、主要シーンで生成、復元、保存されていません。

BootScene は click、explosion、treasure の音声を assets/sounds から読み込もうとしますが、リポジトリのツリーに assets/sounds がありません。

### 3.5 カメラと UI

基本部品は実装されていますが、パン範囲が固定値 2000 で、盤面サイズと画面サイズから導出されていません。GameScene と UIScene のイベント寿命も手動整理が多く、再起動時の確認が必要です。

## 5. 既知の重要不具合とリスク

### P0 起動資産の不整合

BootScene が参照する assets/sounds/click.mp3、explosion.mp3、treasure.mp3 が存在しません。

enemy、key、sword の画像ファイル自体はありますが BootScene でロードしていません。表示コードはこれらのテクスチャを参照します。

完了条件は、ブラウザのコンソールと Network に資産 404 がなく、通常モードと RPG モードのメニューまで到達することです。

### P0 壁配置が既存セルを上書きする

WallPlacementStrategy は壁以外の占有状態を確認せず、地雷、宝、階段、敵を WallLogicCell へ置き換えます。配置済み地雷数と flagsLeft が一致しなくなるほか、鍵や階段が消えて RPG が進行不能になる可能性があります。

### P0 RPG と通常勝利条件の競合

GameSession._checkWinCondition はモードを見ません。RPG でも地雷と壁以外をすべて開くと isGameOver と win が設定され、階段による周回設計と競合します。

### P0 目標仕様とデータモデルの不一致

既存 RPG 仕様書はベースセルと被覆セルの重なりを前提にしていますが、実装は一座標一 LogicCell です。小修正で埋められる差ではなく、モデル設計の決定が必要です。

### P1 カスタム RPG の敵数が暗黙値

カスタム画面に enemies がなく、GameConfig.updateConfig のマージによって直前設定の敵数が残ります。バリデーションの特殊セル合計にも敵が含まれません。

### P1 宝イベント名の不一致

ロジックの TREASURE_GOLD と表示側の TREASURE が一致しません。

### P1 壁の旗状態がモデルと表示で不一致

WallLogicCell は通常の toggleFlag を使用できる一方、WallCell.toggleFlag は常に false を返します。

### P1 宝の取得済み状態が表示へ同期されない

表示更新が cellData.state と treasureContent を継続的に渡していません。

### P1 新しいゲーム操作の再起動重複

UIScene.restartGame は GameScene.restartGame を連続して二回呼び出しています。二重再起動やイベント残留の原因になり得ます。

### P2 ソースコメントの文字化け

BoardGenerator.js の日本語コメントが文字化けしています。実行ロジックへの直接影響はありませんが、保守性を下げています。

### P2 不要物と重複資産

backup と trash に旧コードや一時スクリプトが残っています。jpg と png で実体が同じ資産もあります。削除は履歴確認後に別作業として行うべきです。
