# 2026-10-17 公開版の起動修正

GitHub PagesのRPG画面で起動前の白い画面を再現。ブラウザのコンソールで、無指定RexUIが `Can't supported version : 3`、`Cannot read properties of undefined (reading 'Defaults')` を出し、その後 `main.js` が `rexuiplugin is not defined` で停止することを確認した。画像や音声のpreloadに到達する前のエラー。

通常／RPGのHTMLで、RexUIのURLを上流コミット `0112498f036d7ed0761c173d9ce665d67e728cdd` に固定した。このコミットのpackage.jsonはRexUI 1.60.0、開発対象Phaser ^3.60.0と明記している。ゲーム本体のPhaser 3.60.0は変更しない。

上流参照: https://github.com/rexrainbow/phaser3-rex-notes/blob/0112498f036d7ed0761c173d9ce665d67e728cdd/package.json

`test/entrypoints.test.js` に両入口の版固定・読込順の回帰確認を追加。`npm test` は45件成功。

## 公開版の確認結果

修正コミット `0ed6ebbafde22500cfed5a4f2f325667bf476655` のGitHub Pages公開成功後、クラウドChromeで以下を確認した。

- 通常／RPGとも、新しい固定URLを読み込み、メニューと初級盤面を表示。
- 通常モードは最初のセル操作で連鎖公開と数字表示が動作。
- RPGは最初のセル公開、宝箱取得による100点加算と開封済み表示、右クリックの旗、消音切替、メニュー復帰が動作。
- これらの操作後、ゲームページと依存ライブラリからのエラー／警告は0件。ブラウザ拡張機能自身のエラーはゲームの判定から除外。
