# RPG 多層モード 初版（2026-10-17）

## 入口と今回の範囲

`index.html` から通常・RPGシンプル・RPG多層を選択する。従来の `rpg.html` はシンプル専用のまま、`layered.html` を多層専用の入口として追加した。両RPG画面の横にはセルの役割と左右クリックの説明を常時表示する。画面幅1030px以下では説明を盤面の下へ配置する。

既存 `docs/rpgモード仕様.md` の多層構造、被覆優先の手動操作、ベースのみを見る自動開放、消耗する剣・つるはしを実装した。旧文書の記載が矛盾する部分は、この文書の初版ルールを現行実装とする。SIMPLEの確定仕様は変更していない。

## セルの構造

二次元配列の各座標は `LayeredCell`。`base` を必ず一つ持ち、`cover` は壁・敵のどちらか一つ、または無し。壁と敵は重複しない。ベースは空白・数字・地雷・宝箱・階段。地雷数は覆いの有無にかかわらずベースの地雷だけを数える。

`isRevealed` は現在最上面にある層が見えるかどうかを表す。覆いが見えても下層は開いたことにならない。覆いを除去した瞬間に `isRevealed=false` へ戻し、下層の内容・取得状態を保存する。同じ操作で下層を開くことはない。

表示は `getViewState` / `getViewData` のプレーンな表示データを経由する。SIMPLEにも同じ取得口を追加し、画面側にLogicCellのインスタンスを直接渡さない。多層専用 `LayeredCellView` は毎回現在の最上面を描くため、覆い除去後に旧壁画像や下層の地雷画像が残らない。覆いの表示に「覆」の印を付ける。ゲームオーバー時は覆いを残し、下層の地雷・宝箱・階段などを小さな印でも表示する。

## 手動操作

左クリックは最上面を公開し、その要素の処理を行う。旗付きセルは操作しない。

- 壁：つるはしが無ければ壁を表示するだけ。あれば1本を消費してその1マスだけを除去する。壁クラスターは生成形状であり、一括破壊単位ではない。
- 敵：剣があれば1本を消費して除去し、50点を一度だけ加える。剣が無ければ最初の手動クリックからゲームオーバー。自動で姿が見えただけでは敗北しない。
- 地雷：覆いがない地雷を開くとゲームオーバー。
- 宝箱：最初は表示、表示済みの宝箱をクリックすると内容を一度だけ取得。金貨は階ごとの `treasurePoints`、鍵はその階の所持フラグ。剣・つるはしの宝箱は表示本数を所持数へ加える。多層の装備取得にはSIMPLEの剣の50点ボーナスを付けない。
- 階段：覆いがなく、この階の鍵を所持していれば左クリックで次階を予約する。敵全滅は不要。鍵がない場合も階段の姿は表示し、理由を通知する。未公開の階段を鍵所持で直接クリックした場合はその一回で利用する。
- 数字：表示済みの数字をクリックすると、周囲の旗数が一致した場合に未開放の周囲を公開する。覆い付きセルは姿を見せるだけで、装備は消費しない。旗を間違えて露出した地雷を開けば敗北する。

右クリックは、最初の左クリック後から「未開放の最上面」に対して旗を切り替える。公開済みの壁・敵にも旗を付けない。これは旧文書の「任意の未開封セル」という共通規則に合わせたもの。旗の上限は地雷数。覆い除去後に再び未開放になった下層には旗を付けられる。

## 自動開放

空白からの幅優先探索では、覆い・宝箱・階段の存在で伝播を止めない。ベースの地雷と旗を除外し、ベースの隣接地雷数が0ならさらに周囲へ進む。覆い付きの安全なセルでは覆いだけを表示する。地雷を覆っている壁や敵はこの自動展開では表示しない。

この処理で壁破壊、敵撃破、道具消費、宝箱取得、階段利用は発生しない。

## 盤面生成と階内完結

初手の周囲3×3（端では切り詰め）には地雷・宝箱・階段・覆いを置かない。アイテムの位置と周囲を安全領域として予約し、残りへ指定数の地雷を配置して数字を計算する。宝箱・階段はいずれも周囲地雷0のベースに配置する。その後、ベースを保持したまま壁クラスターと敵を重ねる。旧案の単純な地雷先行配置を変更したのは、後半階でも装備用の安全領域を確保するため。

宝箱は鍵用に1個、敵がいれば剣用に1個、壁がいればつるはし用に1個を必要とし、残りは金貨。装備の宝箱には敵の総数と同数の剣、壁の総数と同数のつるはしを入れる。装備箱には覆いを付けず、初手からの自動開放で姿が見える場所へ置く。鍵・金貨・階段には覆いを配置できる。

全ての壁を壊し全ての敵を倒しても道具が不足しない。壁に隠されたつるはしでその壁を壊すような循環依存は発生しない。通常のマインスイーパーとして推測なしで解けることまでは保証しない。

初級の宝箱は4個（鍵・剣・つるはし・金貨）、中級5個、上級8個。地雷・敵・壁・階段の標準個数は従来と同じ。階に応じた地雷増加・金貨価値増加を継続する。検証はベース容量と覆い容量を別々に数える。生成は最大32回で打ち切り、配置数を勝手に減らさない。面積上の検証を通る全てのカスタム値で、アイテム周辺の安全領域と連結した壁の配置が成功するとは限らない。失敗時は再クリックまたは設定変更に戻れる。

次階では鍵・剣・つるはしを全てリセットする。階得点は0、総得点だけ累計で保持する。階層移動中は入力を止め、一度だけ更新する。探索はエンドレス。
