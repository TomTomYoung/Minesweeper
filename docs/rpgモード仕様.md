# RPGモード仕様書

## 1. 概要
RPGモードは、通常のマインスイーパーに「冒険」と「周回」の要素を加えた拡張モードです。
単に地雷を除去するだけでなく、障害物（壁）を回避しつつ、お宝を回収し、階段を見つけて次のレベル（階層）へ進むことを目的とします。

## 2. 通常モードとの違い

### システム的な基本セル種 (LogicCell)
システム上、セルの種類ごとの固有の振る舞いは、ポリモーフィズムを用いた個別のクラス (`EmptyLogicCell`, `MineLogicCell`, `WallLogicCell` など) に委譲されています。ベースとなる基本セル種は以下の4つのグループのいずれかに属します。
**【同一基本セル種の重複配置不可ルール】**
同種のセルが同じ座標に重複して配置されることはありません。「同種」とは、この「基本セル種」のことを指します。（例：【被覆】クラスである `WallLogicCell` と `EnemyLogicCell` が同一セルに重なることはない。また、【地雷】の上に【地雷】が重なることもありません。）

*   **数字**: 周囲（対象セルに隣接する縦・横・斜めの最大8セル）の地雷セル（カウント対象）の数を示す。
*   **空白**: 周囲（同上）に地雷セルがないことを示す。
*   **地雷**: 数字セルのカウント対象となる要素。
*   **被覆**: 他の基本セル（地雷、空白、数字）の上に被さるように配置される要素。

### セルの状態（未開封と開封）
セルの状態遷移は、基本的に以下の2つの状態のみで管理されます。

*   **未開封（Unrevealed）**: 初期状態。セルの現在の状態・種類が見えない状態（グレーのマス）。
    *   見えないがセルは存在します。よってこの状態のマスを**左クリック**すると、マスの現在の状態に対応する**コマンドが発動**し、状態が「開封」へ遷移します。（例：「空白」なら自動オープン発動へ、「ボム（地雷）」ならゲームオーバーへ遷移）。
*   **開封（Revealed）**: セルの現在の状態・種類が見える状態。
    *   常に、そのマスの現在の状態に応じた画像（例：`wall.png`など）が見えなければならない状態です。
    *   **壁セルの挙動例**: ある未開封セルが「壁」だった場合、つるはし所持状態なら左クリックで破壊コマンドが完了します。つるはし未所持なら何もコマンドは起きません。しかし、コマンドの成否に関わらず左クリックした時点で未開封から開封状態になるため、`wall.png` は見えなければなりません。

### 自動オープン（Auto-Open）
プレイヤーのクリックによって発動した「空白（数字0）」マスの展開によって引き起こされる連鎖処理です。
*   **ベースセルのみを判定**: 自動オープンは、被覆セル（壁など）の存在を完全に無視し、下にある「ベースセルの基本種（地雷、数字、空白など）」だけを見て伝播・判定を行います。
*   **未開封状態からの遷移と継続**:
    *   **空白や数字に被覆した壁**: ベースセルが開示条件を満たすため、対象セルは「未開封」から「開封」状態へ遷移します（重なっている `wall.png` が見えるようになる）。そして、被覆セルに関係なく**自動オープンの波は止まらずにそのまま継続・伝播**します。
    *   **ボム（地雷）に被覆した壁**: 自動オープンは地雷を開かない仕様であるため、ベースセルが開示条件を満たさず、対象セルは「未開封」のままとなります（壁すら見えません）。
*   **コマンドの発動有無について**: 自動オープンの連鎖展開によって【開封】状態に遷移した場合でも、左クリックによる手動の干渉とは異なり、自動オープンの波を浴びた被覆マス自身の独自**コマンド（壁の破壊など）は発動しません**。（壁は開封されて姿を表すが、破壊はされずにその場に残る）。

### 基本セル種の階層構造（重なり）とコマンドの優先度
セルの属性は平面的な「状態遷移（1つのセルが変わる）」ではなく、「重なり（多層）」として表現されます。
*   あらゆるセル種上に被覆セルが配置される可能性があります（例：本物の地雷の上に敵が配置される等）。
*   ある未開封セルをクリックした場合、**一番上に重なっているセルの挙動が最優先**されます。
    *   例：「壁」が重なっている未開封セルをクリックした場合、つるはし所持状態なら「壁の破壊」コマンドが発動する。つるはし未所持なら、壁の破壊は行われないし、コマンド自体は何も起きない。
    *   しかし、コマンドの成否に関わらず、クリックしたことで**「未開封」から「開封」状態への遷移**は行われるため、そのセルの正体（壁画像など）は必ず見えるようになります。
*   自動オープン（空白セル展開）に巻き込まれた場合も同様に、対象セルは「未開封」から「開封」状態へ遷移し、画像が見えるようになります。
*   被覆セルが「破壊」コマンドによって除去された場合、その下にあったベースセル（地雷・数字・空白など）が、そのまま「未開封状態」としてゲーム盤面に現れます（露出）。これはセルの状態遷移ではなく、物理的な覆いが除去されただけという扱いです。

| 項目 | RPGモード | 通常モード (Standard) |
| :--- | :--- | :--- |
| **勝利条件** | 階段を見つけて次のレベルへ進む（エンドレス）<br>※全セルを開ける必要はない | 全ての地雷以外のセルを開ける |
| **地雷以外のセル** | 空白、数字、**壁**、**敵**、**お宝**、**鍵**、**階段** | 空白、数字 |
| **壁・敵の扱い** | 存在する（被覆セルとしてベースセルの上に乗る）。<br>これら自体は数字の計算に**含まれない**。 | 存在しない |
| **レベル機能** | あり。階層が進むごとに難易度上昇。 | なし（1回完結） |
| **スコア** | お宝獲得やクリアで加算され、引き継がれる。 | タイムやクリア状況のみ |

## 3. ゲームメカニクス

### 3.1 セルの分類（基本セルと特殊セル）
RPGモードに登場するあらゆるセルは、システム上必ず前述の「基本セル種（地雷、空白、数字、被覆）」のいずれかに属しています。分類ごとに以下の役割や特殊セルが存在します。

#### 1. 【地雷】に属するセル（数字セルのカウント対象）
*   **通常の地雷 (Mine / Bomb)**
    *   **左クリック**:
        *   **システムコマンド**: 「ゲームオーバー」を発行。
        *   **セル遷移**: 【未開封】から【開いた地雷（爆発）】へ遷移。
    *   **右クリック**:
        *   **システムコマンド**: 「旗の設定／解除」を発行。
        *   **セル遷移**: 【未開封】と【旗あり】をトグル遷移。

#### 2. 【空白】に属するセル（周囲に地雷・カウント対象がないセル）
プレイヤーに有利な効果をもたらす特殊セルは、すべてこの「空白」条件を満たす場所に配置されます。
*   **通常の空白セル**
    *   **左クリック**:
        *   **システムコマンド**: 周囲のセルへの「自動展開（連鎖びらき）」を発行。
        *   **セル遷移**: 【未開封】から【開いた状態（空白）】へ遷移。
    *   **右クリック**:
        *   **システムコマンド**: 「旗の設定／解除」を発行。
        *   **セル遷移**: 【未開封】と【旗あり】をトグル遷移。
*   **お宝 (Treasure / Chest)**
    *   **左クリック**:
        *   1回目（未開封時）:
            *   **システムコマンド**: なし（中身の確認のみ）。
            *   **セル遷移**: 【未開封】から【中身表示（宝箱オープン）】へ遷移。
        *   2回目（中身表示時）:
            *   **システムコマンド**: 「アイテム取得効果（スコア加算、鍵フラグON等）」を発行。
            *   **セル遷移**: 【中身表示】から【取得済み（空の宝箱）】へ遷移。
    *   **右クリック**:
        *   **システムコマンド**: 「旗の設定／解除」を発行（未開封時のみ）。
        *   **セル遷移**: 【未開封】と【旗あり】をトグル遷移。
    *   **中身の種類**:
        *   **財宝 (Gold)**: スコアを獲得できる。レベル上昇に伴い価値が上がる(`treasurePoints`)。
        *   **鍵 (Key)**: 階段のロックを解除するために必要なアイテム。レベル内に必ず1つは配置される。
        *   **剣 (Sword)**: 【被覆】セルである「敵 (Enemy)」を排除するために必要なアイテム。敵セルをクリックすると自動的に消費される。
        *   **つるはし (Pickaxe)**: 【被覆】セルである「壁 (Wall)」を破壊するために必要なアイテム。壁セルをクリックすると自動的に消費される。

*   （※以前は「鍵」が単独のセルとして存在したが、現在は「お宝」の中身の1つとして統合されている。）

*   **階段 (Stairs)**
    *   盤面上のどこかに隠された、次のレベル（階層）へと進むための出口。
    *   **左クリック**:
        *   鍵・未取得時:
            *   **システムコマンド**: 「階段ロック中」の警告・フィードバックを発行。
            *   **セル遷移**: 遷移なし（【未開封】のまま）。
        *   鍵・取得時:
            *   **システムコマンド**: 「ステージクリア（次のレベルへ移動）」を発行。
            *   **セル遷移**: 【未開封】から【使用済み（階段解放）】へ遷移。
    *   **右クリック**:
        *   **システムコマンド**: 「旗の設定／解除」を発行。
        *   **セル遷移**: 【未開封】と【旗あり】をトグル遷移。

#### 3. 【数字】に属するセル
*   **通常の数字セル**
    *   周囲の【地雷】に属するセル（通常地雷など）の数を表示するセル。特殊な役割は付与されません。
    *   **左クリック**:
        *   **システムコマンド**: なし（通常の展開のみ）。
        *   **セル遷移**: 【未開封】から【開いた状態（数字表示）】へ遷移。
    *   **右クリック**:
        *   **システムコマンド**: 「旗の設定／解除」を発行。
        *   **セル遷移**: 【未開封】と【旗あり】をトグル遷移。

#### 4. 【被覆】に属するセル
*   **敵 (Enemy)**
    *   地雷、数字セル、階段セルなどのベースとなるセルの「上」に重ねて配置される危険な被覆セル。
    *   **左クリック**:
        *   アイテム「剣」未所持の場合:
            *   **システムコマンド**: 「ゲームオーバー」を発行。
            *   **セル遷移**: 遷移なし（またはゲームオーバー状態へ遷移）。
        *   アイテム「剣」所持の場合:
            *   **システムコマンド**: 「剣」を消費し、「敵セルの排除」を発行。
            *   **セル遷移（重なりの除去）**: 【敵あり（被覆中）】から被覆状態を解除し、下のベースセルを【未開封】状態で露出させる。
    *   **右クリック**:
        *   **システムコマンド**: 「旗の設定／解除」を発行。
        *   **セル遷移**: 【旗なし】と【旗あり】をトグル遷移。
    *   **重複配置**: 前述の通り、【被覆】という同じ基本セル種に属する「壁」などと同一座標に重複して配置されることはありません。

*   **旗（Flag）**
    *   プレイヤーは任意の未開封セルに旗を立てることができます。旗が立っているセルは左クリックや自動オープンの対象外となります（保護機能）。旗は右クリックで着脱可能です。

*   **ゲーム終了時（ゲームオーバーおよびクリア時）の挙動**
    *   勝敗にかかわらず、ゲームが終了した瞬間に盤面上の **全てのセル（地雷、壁、数字セル、お宝等を含む）が強制的に【開封】状態** に遷移し、その正体が明らかになります。

*   **壁 (Wall)**
    *   地雷、数字セル、階段セルなどのベースとなるセルの「上」に重ねて配置される障害物。
    *   **注意**: 壁が特別に「下のセルを妨害する能力」を持っているわけではありません。前述の通り被覆セルに対するクリックが常に最優先されるため、「つるはし未所持時にクリックしても『何も起きない』という壁自身の挙動」が処理された結果として、その下にあるベースセルへ判定が届かない（妨害されたように見える）構造になっています。
    *   **左クリック**:
        *   アイテム「つるはし」未所持の場合:
            *   **システムコマンド**: なし（被覆によって下のセルのクリックがブロックされる）。壁の破壊も行われない。
            *   **セル遷移**: 【未開封】から【開封】へ遷移し、壁画像（`wall.png`）が表示される。
        *   アイテム「つるはし」所持の場合:
            *   **システムコマンド**: 「つるはしを消費」し、「壁の破壊」を発行。
            *   **セル遷移（重なりの除去）**: 【壁あり（被覆中）】から被覆状態を解除し、下のベースセルを【未開封】状態で露出させる。
    *   **右クリック**:
        *   **システムコマンド**: 「旗の設定／解除」を発行。
        *   **セル遷移**: 【旗なし】と【旗あり】をトグル遷移。
    *   **特徴**: ベースとなるセルを覆い隠す物理的な障害物として機能します。「つるはし」を使わなければどかすことはできません。
    *   **生成**: クラスター状（塊）に生成されることが多い (`wallClusters` 設定)。ベースとなるセル（地雷や空白）の配置後に上書き・被覆する形で生成されます。

### 3.2 進行と難易度上昇 (Leveling)
レベル（階層）が進むごとに難易度が調整されます (`GameConfig.adjustForLevel`)。

*   **地雷数**: レベルが1上がるごとに約10%増加する（上限は全セルの30%）。
*   **お宝スコア**: レベルが1上がるごとに20%増加する。

### 3.3 用語定義と生成ロジック (Cluster System)

本モードでは、安全地帯と危険地帯を以下の用語で定義し、生成順序によってこれを実現しています。

#### 用語定義
*   **地雷 (Mine / Bomb)**: 数字セルのカウント対象となる危険セル。クリックするとゲームオーバー。
*   **特殊セル (Special Cell)**: プレイヤーに有利な効果をもたらす基本セル（空白）上の要素の総称。
    *   **宝 (Treasure)**: 獲得すると得点になる。
    *   **鍵 (Key)**: 階段のロックを解除するアイテム。
    *   **階段 (Stairs)**: 次の階へ進むための出口。鍵が必要。
*   **被覆セル (Cover Cell)**: ベースとなるセルの上に重なる要素。これら自体は数字（カウント）の対象にならない。
    *   **敵 (Enemy)**: 剣でのみ排除可能な危険な被覆。剣未所持でクリックするとゲームオーバー。
    *   **壁 (Wall)**: 障害物となる被覆。つるはしでのみ破壊可能。

*   **クラスター (Cluster)**: 地雷と対になる安全な領域の総称。
*   **クラスター内部 (Cluster Inner Shell)**: クラスターから数字セルを引いたものであって、数字が配置されることもない。特殊セル（宝・鍵・階段）が配置される領域。
*   **クラスター外郭 (Cluster Outer Shell)**: クラスター内部を囲む「数字セル」の領域。ここにも地雷は存在しないが、そのさらに外側（地雷原）と隣接している。

#### 実装順序 (Generation Order)
本モード（パターンB準拠）の生成順序は以下の通りです。

1.  **盤面初期化**: 全てを「通常セル」として初期化。
2.  **安全地帯 (Safe Zone) 確保**: 初回クリック位置の確保。
3.  **地雷 (Mines) の配置**:
    *   地雷をランダムに配置する。
    *   これらは「危険地帯」を形成する。
4.  **アイテム (Items) や被覆の配置**:
    *   特殊セル（宝・鍵・階段）を配置する。
    *   **条件**: 地雷が存在せず、かつ**周囲8マスに地雷がない安全な場所（クラスター）**を選んで配置する。
    *   これにより、アイテムの取得には必ず「数字セルの攻略」が必要となる構造が保証される。
    *   （※その後、壁や敵などの【被覆】セルが配置される）

#### 実装機能
*   **地雷/エネミー配置**: ランダム配置 (`MinePlacementStrategy`, `EnemyPlacementStrategy`)
*   **アイテム配置**: 安全地帯探索 (`ItemPlacementStrategy`)
    *   地雷原の隙間（安全なポケット）を見つけて、そこにお宝や鍵、階段を隠す。

## 4. スコアリングと保存
*   **スコア**: お宝の獲得、レベルクリアなどで加算されます。
*   **保存**: `SaveManager` により、モードと難易度ごとにハイスコアが保存されます。
    *   保存キー: `minesweeper_rpg_highscore_[mode]_[difficulty]`

## 5. UI/UX
*   **モード選択**: メニュー画面で「RPGモード」と「通常モード」を切り替え可能。
*   **カスタム設定**: RPGモードの要素（壁の数、お宝の数など）を細かく調整してプレイすることも可能。

## 6. アーキテクチャ (実装詳細)
*   RPGモードにおける複雑なセルの効果発動（壁の破壊、アイテム取得、敵の撃破など）は、中央の `BoardModel` が条件分岐で行うのではなく、各セルの実体である `LogicCell` クラス群のメソッド（例：`TreasureLogicCell.interact()`, `EnemyLogicCell.reveal()`）によって判定・実行されます。
*   これにより、今後新しい特殊要素を追加する際も、コアロジックを汚さずにセルクラスの追加だけで安全に拡張できる設計（ポリモーフィズム）となっています。
