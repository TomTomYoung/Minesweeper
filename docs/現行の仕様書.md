# マインスイーパー (現行仕様書)

## 1. 概要
本プロジェクトは、Phaser 3を使用したWebブラウザ向けマインスイーパーゲームである。
通常のマインスイーパーに加え、壁、お宝、階段といったRPG要素を含む拡張ルールが実装されている。

## 2. ゲームルール

### 2.1 勝利条件
*   地雷および壁以外の全てのセルを開くこと。
*   勝利時、残り時間と残り旗数に応じたボーナススコアが加算される。

### 2.2 敗北条件
*   地雷が埋まっているセルを開くこと。

### 2.3 基本操作
*   **左クリック**: セルを開く。
*   **右クリック**: 旗（フラグ）を立てる/解除する。
*   **数字クリック (ダブルクリック相当)**: 開いている数字セルの周囲にある旗の数がその数字と一致している場合、周囲の未開封セルを一括で開く。

### 2.4 特殊セル
通常の地雷に加え、以下の特殊セルが存在する。

| 種類 | 説明 |
| :--- | :--- |
| **壁 (Wall)** | 通行不可のセル。自動展開（BFS）をブロックする。壁クラスター（集合体）を形成することがある。 |
| **お宝 (Treasure)** | 開くとボーナススコア（100点）を獲得できる。周囲の自動展開は止まる。 |
| **階段 (Stairs)** | 開くと「次のレベル」へ進む判定が行われる（詳細な遷移ロジックはGameScene側で制御）。 |
| **地雷 (Mine)** | 開くとゲームオーバー。 |

## 3. ゲームシステム詳細

### 3.1 ボード生成 (BoardGenerator)
*   **安全地帯**: 最初のクリック位置およびその周囲8マスには、地雷、壁、お宝、階段は配置されない。
*   **生成順序**:
    1.  安全地帯の確保
    2.  壁クラスターの配置
    3.  地雷の配置
    4.  お宝・階段の配置（安全な場所のみ）
    5.  隣接情報の計算
*   **隣接計算オプション**: 「壁を地雷数に含めるか」の設定が可能。

### 3.2 探索ロジック (BoardModel と LogicCell群)
*   **ポリモーフィズム (多態性)**: セルごとの固有の振る舞い（開かれた時、さらにクリックされた時）は、`BoardModel` で集中的に判定するのではなく、各セルのクラス (`EmptyLogicCell`, `MineLogicCell`, `WallLogicCell` など) に委譲されている。
*   **BFS (幅優先探索)**: 空白セル（隣接地雷数が0）を開いた際の再帰的な展開処理は、`EmptyLogicCell` 内部で処理される。
    *   壁セルは拡散をブロックする。
    *   お宝、階段セルで拡散は停止する。
*   **壁クラスター**: 設定により、壁の集合体を一括で開く（可視化する）機能は、`WallLogicCell` 内部で処理される。

### 3.3 スコア計算 (GameSession)
*   **獲得スコア**: お宝発見時に加算。
*   **ボーナススコア** (勝利時):
    *   時間ボーナス: `Max(500 - 経過秒数, 0)`
    *   旗ボーナス: `残り旗数 * 10`

## 4. 構成設定 (Configuration)

### 4.1 難易度プリセット
| 難易度 | 行 (Rows) | 列 (Cols) | 地雷 (Mines) |
| :--- | :--- | :--- | :--- |
| 初級 | 9 | 9 | 10 |
| 中級 | 16 | 16 | 40 |
| 上級 | 16 | 30 | 99 |

### 4.2 カスタム設定
ユーザーが以下の項目を自由に設定可能。
*   グリッドサイズ (行/列)
*   地雷数
*   壁クラスター数、壁総数
*   お宝数、階段数
*   **オプション**:
    *   壁を数字計算に含める (ON/OFF)
    *   壁クラスターを自動公開 (ON/OFF)

## 5. 技術スタック & アーキテクチャ
*   **フレームワーク**: Phaser 3 (Rendering, Input)
*   **アーキテクチャ**: MVCライク + オブジェクト指向な設計
    *   `BoardModel.js`: 純粋なデータモデル。盤面構造を保持し、各イベントを `LogicCell` に委譲する。Phaser非依存。
    *   `LogicCell` 群 (`src/logic/cells/`): セルごとの状態と固有の振る舞い（ポリモーフィズム）をカプセル化した中核クラス。
    *   `GameSession.js`: ゲームの進行管理（スコア、時間、勝敗判定）。Controller的役割。
    *   `BoardGenerator.js`: プロシージャル生成ロジック。各種 Strategy を使って `LogicCell` 群のインスタンスを生成・配置する。
    *   `GameScene.js`: View担当。Phaserオブジェクトの管理と入力をSessionに伝達。
    *   `Cell.js` (及び描画用派生クラス): 各セルの表示用オブジェクト。

## 6. ファイル構成
*   `index.html`: エントリーポイント。CDN経由でPhaserをロード。
*   `src/config.js`: 見た目（色、フォント）の設定定数。
*   `src/logic/`: ゲームロジック (コア判定、生成)。
*   `src/scenes/`: 画面遷移 (Boot, Menu, Game, UI)。
*   `src/objects/`: ゲーム内オブジェクト (Cell等)。
