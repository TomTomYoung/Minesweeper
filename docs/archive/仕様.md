# 技術仕様書 (Technical Specification)

## 座標・サイズ管理仕様 (Coordinate & Size System)

### 1. 概要
本プロジェクトでは、ゲームロジック上の「グリッド座標」と、描画上の「ピクセル座標」を明確に区別して管理する。
GUIや各種関数は、その役割に応じて適切な座標系を選択する必要がある。

### 2. データフローと変換プロセス

#### 2.1 起点 (Configuration)
座標計算の全ての基準は `GameScene.initGameSession` および `GameConfig` で決定される以下の値である。
*   `cellSize` (px): セルの1辺の長さ (例: 40)
*   `rows`, `cols`: グリッドの行数・列数 (例: 16, 30)

#### 2.2 座標変換フロー

1.  **ボード配置位置の決定 (Global Positioning)**
    *   **関数**: `GameScene.createGameBoard(rows, cols, cellSize)`
    *   **計算式**:
        ```javascript
        boardWidth = cols * cellSize
        boardHeight = rows * cellSize
        boardX = (ScreenW - boardWidth) / 2  // 画面中央揃え
        boardY = 70                          // ヘッダーUI分のオフセット
        ```
    *   **結果**: `Board` (Container) が `(boardX, boardY)` に配置される。

2.  **セル配置位置の決定 (Local Positioning)**
    *   **関数**: `Board.createBoard()` -> ループ内で計算
    *   **計算式**:
        ```javascript
        localX = col * cellSize
        localY = row * cellSize
        ```
    *   **結果**: 各 `Cell` (Container) は `Board` コンテナ内の `(localX, localY)` に配置される。
    *   **重要**: `Cell` の `Origin` は `(0, 0)` (左上) である。

3.  **セル内部要素の配置 (Inner Layout)**
    *   **関数**: `Cell.createVisuals()`
    *   **背景**: `(0, 0)` (Origin 0,0)
    *   **テキスト/アイコン**: `(size/2, size/2)` (Origin 0.5, 0.5) で中心配置。

### 3. 各レイヤーが使用すべき座標系

| レイヤー/クラス | 使用する座標系 | 単位 | 具体例 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **Logic (Model)**<br>`BoardModel`, `GameSession` | **Grid Coordinates** | Index (Integer) | `(row, col)`<br>例: `(0, 0)` | グリッドの左上を `(0, 0)` とする。 |
| **View (Board/Cell)**<br>`Board`, `Cell` | **Local Pixel Coordinates** | Pixel (Float) | `(x, y)`<br>例: `(40, 0)` | 親コンテナからの相対座標。<br>`x = col * cellSize` |
| **View (Effect/UI)**<br>`Particles`, `Tooltip` | **World Pixel Coordinates** | Pixel (Float) | `(worldX, worldY)` | `Board.x + Cell.x`<br>または `cell.getBounds()` で取得。 |
| **Input (Mouse)**<br>`Pointer` | **World Pixel Coordinates** | Pixel (Float) | `pointer.worldX` | カメラのスクロールを考慮したワールド座標。 |

### 4. サイズ・スケール仕様

*   **基準サイズ (`cellSize`)**: 全ての描画サイズの基準。 `GameConfig` で定義。
*   **アイコンサイズ**: `cellSize * 0.8` (80%) を基準とし、セル内に収まるようにスケーリングする。
*   **フォントサイズ**: `config.js` または `cellSize * 0.6` など、`cellSize` に比例させて計算する。

### 5. 注意事項

*   **GUI実装時**:
    *   セルの上にポップアップなどを出す場合は、単純な `cell.x` ではなく、`board.x + cell.x` (World座標) を使用すること。
    *   Phaserの `Container` のネスト構造に注意する (`GameScene` -> `Board` -> `Cell`)。
*   **座標変換関数**:
    *   Logic -> View: `board.cells[row][col]` でセルオブジェクトを取得し、その座標を参照可能。
    *   View -> Logic: クリック判定等は `Board` 内でイベントとして処理され、`cell.boardRow`, `cell.boardCol` を通じてLogic層へ伝達される。

## 操作仕様 (Input Specification)

### 1. マウス操作 (Mouse Controls)

| 操作 | アクション | 処理クラス |
| :--- | :--- | :--- |
| **左クリック** (Left Click) | **セルを開く** (Reveal Cell) | `Cell.js`, `InputController.js` |
| **右クリック** (Right Click) | **旗を立てる/解除** (Toggle Flag) | `Cell.js`, `InputController.js` |
| **ホイール押し込み + ドラッグ** (Middle Drag) | **カメラパン** (Pan Camera) | `CameraController.js` |
| **マウスホイール** (Mouse Wheel) | **ズームイン/アウト** (Zoom In/Out) | `CameraController.js` |

*   **注記:**
    *   ホイール押し込み（中ボタン）によるセル操作（リビール等）は無効化されています。
    *   パン操作は `Ctrl` キー不要で、ホイールボタン押し込みドラッグのみで機能します。
