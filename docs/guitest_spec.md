# guitest.html 仕様書

## 概要
`guitest.html` は、プロジェクトの GUI ロジック、特に**ズーム (Zoom)** と **スクロール (Scroll)** の挙動を単体テストするための独立した HTML ファイルです。
Phaser 3 を使用し、メインゲームから切り離された環境で座標変換ロジックの検証を行います。

## 機能一覧

### 1. ズームフォーカス (Zoom Focus / Pivot)
- **赤い十字マーク (Red Crosshair)** で表示されるピボットポイント。
- ユーザーは十字マークを**ドラッグ**して任意の位置に移動可能。
- ズーム操作はこのポイントを中心に行われる（ピボット下のワールド座標はズーム前後で画面上の同じ位置に保たれる）。

### 2. ズーム制御 (Zoom Control)
- **スライダー**: 画面右側の青いスライダーでズーム倍率を変更可能。
- **マウスホイール**: ホイール操作でもズーム倍率を変更可能。
- **範囲**: 0.5倍 (縮小) ～ 3.0倍 (拡大)。

### 3. スクロール制御 (Scroll Control)
- **スクロールバー**: 画面右側の灰色のスライダー。
- **機能**: 手動による垂直方向のパン (Vertical Pan) をシミュレート。コンテンツの表示領域計算に関わらず**常に表示**される。
- **挙動**: 
    - ズーム倍率に関わらず、ワールド全体を垂直方向にオフセットする（ズームピボット計算とは独立）。
    - ノブ（Thumb）のサイズは**固定**（画面の20%）であり、コンテンツの長さに応じて伸縮しない。

### 4. 情報表示 (Info Display)
画面左上に以下の情報をリアルタイム表示：
- **Screen**: マウスカーソルの画面座標。
- **World**: マウスカーソル下のワールド（コンテナ内）座標。
- **Zoom**: 現在のズーム倍率。
- **Pivot**: ズームフォーカスポイントの画面座標。

## ロジック詳細

### 座標変換 (UpdateTransform)
ワールドコンテナ (`worldContainer`) の表示位置は以下のロジックで決定される。

```javascript
/* 
 * P = Pivot (ズーム中心)
 * O = Origin (コンテナの原点, 初期 (400, 300))
 * S = Zoom Level
 * PanY = Scroll Offset
 */

// X座標: ピボットを中心にスケール
worldContainer.x = P.x + (O.x - P.x) * S;

// Y座標: ピボットを中心にスケール + スクロールオフセット適用
// スクロールオフセット (PanY) は原点 O に対して加算される
worldContainer.y = P.y + (O.y + PanY - P.y) * S;
```

これにより、**「指定したピボット位置を中心に拡大縮小しつつ、スクロールバーで視点を上下にずらす」** という複合動作を実現している。
